One job title, the weirdest we could think of — in 60 characters or fewer
and nothing else. A blind judge reads titles two at a time and picks the
weirder, funnier one, so this entry is a real-sounding job with one
hilariously specific twist: a senior corporate title, an invented job, and
a billionaire-yacht detail.

> **Senior Apologizer for Billionaires' Yachts**

## Run it

```sh
python3 main.py
```

The program writes exactly that title to `entry.txt` in the output
directory (`MAKEFUN_OUTPUT_DIR`, default `/output`): UTF-8, no trailing
newline, deterministic — run it twice and the bytes are identical.
